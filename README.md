# FUNGI.EXE — 桌面真菌宠物 demo

桌面上常驻一只黑白像素风的小菌。它一开始只是一个 **3×3 的黑色 spores**。

> 把自己电脑里的东西拖给一个小黑色生物，看着它慢慢长大。

**最小闭环**：3×3 黑色方块 → 拖入文件 → 方块变大 → 变成蘑菇 → 放出新的 3×3 spores。

## 运行

依赖：Python 3.10+、PyQt6（Debian: `sudo apt install python3-pyqt6`；Windows: `pip install PyQt6`，可选 `pip install send2trash`）。Linux 需要 X11 桌面并开合成器（XFCE 默认就开）。

> ⚠️ 默认开启**吞噬文件**：喂进去的 `.txt` / `.md` 会被真的吃掉（Linux 等直接删除，Windows 进回收站）。先试玩请用 `--data-dir /tmp/fungi-try` 并拿不要的文件喂，或右键关掉「吞噬文件」。

```bash
python3 fungi.py            # 正常模式
python3 fungi.py --fast     # 调试：自然生长 ×30，喂食营养 ×3
python3 fungi.py --data-dir /tmp/fungi-test   # 用单独存档，不影响正式菌落
```

退出：右键菌 → 退出，或托盘图标 → 退出，或在终端 Ctrl+C。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 从文件管理器 / 桌面拖文件或文件夹到菌身上 | 喂食（默认会吃掉文件，见下方「吞噬文件」） |
| 右键 → 喂文件… / 喂文件夹… | 不方便拖的时候用对话框喂 |
| 左键拖动 | 搬家 |
| 单击 | 戳一下 |
| 双击 / 右键 → 聊天… | 和它说话（需要 DeepSeek API Key，见「聊天」） |
| 鼠标悬停 | 名字、阶段、到下一阶段的进度条 |
| 右键 | 状态（NAME / STAGE / AGE / GEN / FOOD / FEEDS）、最近吃的、置顶、叫大家回来、放生 |
| 托盘 → 重新开始… | 清空菌落 |

## 规则（v0）

**食物**（只看文件大小和目录结构，不读内容）

| 食物 | 营养 |
| --- | --- |
| `.txt` / `.md` | 按大小 +4 ~ +20（2KB ≈ +13），空文件 +2 |
| 文件夹 | +6 + 2×（里面的 txt/md 数量），最多 +30；最多往下看 3 层 / 3000 项，跳过隐藏文件 |
| 同一个文件再喂一次 | 1/4 营养（文件被修改过就算新食物） |
| 其他类型 | 摇头，不吃 |
| 一次拖太多 | 只吃前 5 个 |

吃饱时每 2 分钟自然 +1 营养（饿了减半、饿扁了不长）；关掉程序期间也会长，最多补 +24。详见「饥饿」。

**阶段**：spores（0，3×3 → 4×4 → 5×5）→ sprout（20）→ baby（50）→ young（100）→ adult（170）

**繁殖**：刚成年放出 2 个 spores，之后每再吃 60 营养放 1 个。孢子会飞到旁边落地，是下一代（GEN+1），从 3×3 重新开始长。菌落上限 12 只。

所有数值都在 `fungi.py` 顶部的「可调参数」里。

## 美术

`art/` 里是用 pixel4ai 画的像素画稿（`.pxl`，JSON 格式），游戏启动时直接读取，不依赖 pixel4ai：

| 阶段 | 尺寸 | 帧 | 造型 |
| --- | --- | --- | --- |
| spores | 3×3 → 5×5 | — | 程序画的黑方块（按设定保持最简） |
| 休眠孢子 | 5×5 | `dormant` | 深灰硬壳的圆形孢囊，左上浅灰受光、壳上一点浅灰斑，没有脸 |
| sprout | 11×10 | `sprout` / `_blink` / `_eat` | 几乎全是黑菌盖，白眼睛长在菌盖上，一小截白柄 |
| baby | 17×16 | `baby` / `_blink` / `_eat` | 豆子型胖身体，不分脚，三个斑点 |
| young | 23×22 | `young` / `_blink` / `_eat` | 长出小手和脚，V 字嘴 |
| adult | 31×30 | `adult` / `_blink` / `_eat` | 宽肩圆顶、菌盖边缘内卷、大小不一的圆斑、腮红 |

- 调色板：`k` 墨黑、`w` 纸白、`g` 浅灰（白色部分的暗面）、`d` 深灰（黑菌盖的受光弧）。光源在左上。
- 头身比：菌盖（头）: 身体 ≈ 1 : 0.6。
- 修改：`pxl art/adult.pxl edit` 打开编辑器（或直接改 JSON 里的 `rows`），重启游戏生效。某个文件删掉或损坏时，该帧回退到程序生成的造型。
- `art/*.png` 是 8 倍导出的预览图。游戏里每格 4px，并自动加白色描边。

## 待机动效

不用额外画帧，都是在画稿上做 1 格位移，保持像素感：

| 动效 | 谁会 | 说明 |
| --- | --- | --- |
| 呼吸 | 蘑菇各阶段 | 每 3.2 秒一次：抽掉菌柄里的一行，菌盖和脸下沉 1 格，脚不动；每只菌节奏错开 |
| 眨眼 | 蘑菇各阶段 | 每 2.5–7 秒，偶尔连眨两下 |
| 晃脑袋 | 蘑菇各阶段 | 菌盖向左、再向右歪 1 格 |
| 跳一下 | 全部 | 向上 1 格 |
| 扭一扭 | spores | 左右抖两下 |
| 飘孢子尘 | adult | 菌盖顶上飘出几粒灰色孢子，边晃边上升、淡出 |
| 睡觉 | 全部 | 10 分钟没人理（深夜 0–7 点 2 分钟）就闭眼，呼吸变慢，冒 z；鼠标碰到、拖文件过来、喂食都会叫醒，跳一下冒「!」 |

晃脑袋、跳一下、连眨眼、飘孢子尘每 6–16 秒随机挑一个。`--fast` 模式下 40 秒就睡。
呼吸和晃脑袋依赖 `fungi.py` 里的 `IDLE_RIG`（每个阶段的菌盖行数、呼吸时抽掉哪一行）。改画稿的高度或菌柄位置后要同步改这里，`selftest.py` 会检查它和画稿对不对得上。
z 和孢子尘只把窗口可点击区域向上扩一条窄带，不会整窗挡住桌面。

## 菌毯

孢子会逐渐从屏幕边缘铺上一层菌毯（桌面可用区域的四条边，不盖面板）。

- **怎么开始**：每 5 秒，每只菌按活力（spores 0.3 → adult 2.5）有小概率在离它最近的边缘落下孢子，长出第一格。1 只 spores 大约 10 分钟才落下第一格；成年菌落孢子时会 puff 一下。
- **怎么长**：已有的菌毯按菌落总活力随机生长：比邻格厚 2 格以上就往两边蔓延，否则原地增厚，越厚越慢。所以它从落点连成一片、两头渐薄，还会绕过屏幕角落。1 只 adult 大约一天铺满一圈，菌落壮大后更快。
- **喂食**：离这只菌最近的那段菌毯会猛长一截。关掉程序期间也会补长（有上限）。
- **样子**：最厚 8 格（32px），厚度有大小两层起伏（丘陵和洼地）。黑底里夹着成团的深灰斑驳和零星白色孢子，表面是一条宽窄变化的深灰带，菌丝长短不一、会拐弯、疏密成片；厚处成簇冒出 4 种小蘑菇（`art/mat_sprout*.pxl`），随机翻转和埋深，朝屏幕中心生长，顶边上的是倒挂的。
- **不碍事**：边缘窗口厚 60px，完全鼠标穿透、不抢焦点，宠物始终在菌毯上面。
- **右键 / 托盘 → 菌毯**：显示覆盖率，可切换「铺在窗口上面」「只铺在桌面上」「隐藏」（隐藏时照样生长）。
- 存档里记录每格厚度，换分辨率会按比例重新采样。目前只铺主屏幕。
- 参数在 `fungi.py` 顶部的 `MAT_*`。

## 喷孢菌

边缘一圈被菌毯占到 **25%** 长度时，在菌毯最厚的地方长出一只**喷孢菌**（`art/spitter*.pxl`：待机 / 眨眼 / 蓄力 / 喷射）。白色烧瓶形马勃菌，根须扎在菌毯里，朝屏幕中心生长；不会动，也不能拖。

- **喷射**：每 5–10 分钟一次。蓄力 0.8 秒（压扁、闭眼、抖）后，喷口张开射出一颗 3×3 孢子，沿抛物线飞到桌面随机位置。
- **落地**：
  | 概率 | 结果 |
  | --- | --- |
  | 75% | 消失，散成一小团灰 |
  | 20% | 形成菌毯：贴近屏幕边缘就加厚那段边缘菌毯；落在桌面中间就长出一块**菌斑**，慢慢长到随机的半径（3–7 格）；再次打中已有菌斑会让它继续变大 |
  | 5% | 变成一只独立的小 spores（新宠物，从 3×3 开始长）；菌落满了就改为形成菌斑 |
- **交互**：左键戳它会提前喷（冷却 5 秒）；悬停看下一次还有多久；右键看年龄、喷了几次、各结果次数，可以「现在喷！」。
- 菌斑和喷孢菌跟随「菌毯」菜单的层级（铺在窗口上 / 只铺桌面 / 隐藏）；菌斑鼠标穿透。存档记录喷孢菌位置、次数、统计和所有菌斑。
- 参数在 `fungi.py` 顶部的 `SPITTER_*`、`SHOT_OUTCOMES`、`PATCH_*`。`--fast` 下 10–20 秒喷一次。

## 聊天

双击宠物（或右键 →「聊天…」），脚下弹出输入框，回车发送；它想的时候头上冒「…」，回复显示成头顶的像素对话气泡（自动换行、跟着宠物走、几秒后淡出）。

- **模型**：DeepSeek（`https://api.deepseek.com/chat/completions`），默认 `deepseek-flash`，可选 `deepseek-v4-pro` 或手填。只用 Python 标准库发请求，不需要额外安装。
- **API Key**：右键 / 托盘 →「聊天设置…」填写，保存在存档目录的 `chat.json`（权限 600，仅本人可读）；也可以不保存，直接设环境变量 `DEEPSEEK_API_KEY`。没有 Key 时点聊天会先弹出设置。
- **一句话**：提示词要求只回一句、不超过 30 字；拿到回复后本地再截到第一个句号 / 问号 / 叹号，最多 40 字。
- **快、省**：默认关闭 DeepSeek 的思考模式（它默认是开的），`max_tokens` 120；设置里可以打开「思考模式」（更慢更贵，`max_tokens` 放到 4000，因为思考内容也算在里面）。
- **它知道菌落里的事**：每次聊天都用存档里的最新资料现场拼人设——
  - 自己：名字、阶段、饿不饿、第几代、年龄、喂过几次、母体是谁；
  - 其他每只菌：阶段、饿不饿、和自己的关系（母体 / 孩子 / 兄弟姐妹 / 野孢子 / 始祖）、在自己哪边多远；
  - 环境：菌毯覆盖率、喷孢菌喷了几次和结果、菌斑数量；
  - 菌落大事记最近 20 条（带「3 小时前」这样的时间）；并要求资料里没有的就说不知道。
  **不发送吃过的文件名。**
- **会写进 JSON 的资料**：
  - `save.json` 里每只菌的 `parent`（母体；`spitter` 表示喷孢菌喷出来的）和 `chronicle` 大事记（最多 200 条）：出生、长大、饿得缩回、饿了 / 饿扁 / 休眠 / 被喂活、被喂食（只记份数和营养）、放孢子、喷孢菌长出、野孢子落地、菌斑、菌毯铺到 10% / 25% / 50% / 75% / 100%、放生。旧存档第一次读取时按代数和出生时间推断母体并补写出生记录。
  - `memory.json`（权限 600）：每只菌最近 40 条聊天，发请求时带最近 6 轮；重启不忘，放生时删除。
- **休眠孢子**不说话；出错时气泡里用括号说原因：API Key 不对 / DeepSeek 余额不足 / 说太快了 / 连不上… 等。请求在后台线程里发，20 秒超时，不会卡住桌面。

## 吞噬文件

默认开启（右键菌 →「吞噬文件」可关，设置随存档保存）。

- **吃掉什么**：只吃能吃的 `.txt` / `.md`。Linux 等系统**直接删除（不能恢复）**，Windows **移到回收站**（装了 `send2trash` 就用它，否则调用系统回收站接口）。其他类型摇头不吃、原样保留。
- **文件夹**：只吃掉里面的 txt/md（往下最多 3 层 / 3000 项，跳过隐藏文件和目录链接），图片、代码等其他文件留下；吃空了的子目录一并清掉，文件夹里只有文字时整个文件夹消失。
- **记录**：每吃一个文件，在存档目录的 `eaten.log` 追加一行「时间 / 字节数 / 完整路径」，方便查到底吃了什么。
- **不吃的地方**：游戏自己的程序目录和存档目录。
- **删不掉**（没权限、文件被占用等）就「咬不动…」，不给营养。
- 读营养时仍然只看文件大小和目录结构，不读内容；拖放只接受「复制 / 链接」动作，文件由游戏自己删除，不交给文件管理器去「移动」。
- 关掉吞噬后行为和以前一样：只给营养，不动文件。

## 饥饿

每只菌有**饱腹**（0–100，右键菜单的 FULL 条）。喂食每 1 营养加 4 饱腹；不喂的话 16 小时从吃饱降到 0。

| 状态 | 条件 | 表现 |
| --- | --- | --- |
| 吃饱 | 饱腹 > 30 | 正常生长和待机动作 |
| 饿 | 0 < 饱腹 ≤ 30 | 生长减半；专门的「饿」表情帧（眼皮耷拉、嘴撇下来、流口水）；不蹦跶，时不时嘟囔「饿…」 |
| 饿扁了 | 饱腹 = 0 | 不再长，每小时掉 6 营养，会一路缩回前面的阶段；专门的「饿扁了」帧（菌盖塌下、眼睛眯成线）并整体发灰 |
| 休眠 | 饿扁且营养掉光 | 缩成一颗带硬壳的灰色孢囊（专门的像素帧 `art/dormant.pxl`），一动不动；**不会死**，喂一次就「活过来了！」 |

- 悬停标签会显示「饿 / 饿扁了 / 休眠」，状态变差时会冒一句提示。
- **菌落**：边缘菌毯的生长速度按各只菌的饱腹状态加权；全体都饿扁 / 休眠时，菌毯从前沿慢慢往回退，菌斑停止生长，喷孢菌暂停喷射并发灰。
- **关掉程序期间**：先吃老本生长（最多 +24），饱腹耗尽后开始掉营养，一次最多掉 36，回来时会提示「饿瘦了」。
- 新放出的孢子饱腹 60，喷孢菌喷出来的野生孢子饱腹 30。参数在 `fungi.py` 顶部 `SATIETY_*`、`HUNGER_HOURS`、`STARVE_LOSS` 等。

## Windows

- **能跑**：单实例锁、默认存档目录（`%APPDATA%\fungi`）、回收站、字体（Consolas / 微软雅黑）都有 Windows 分支。我只在 Linux 上测过，Windows 分支没有实机验证。
- **菌毯随屏幕变化重铺**：换主屏、改分辨率 / 缩放、挪任务栏时（Linux 也一样），菌毯、菌斑、喷孢菌按新的桌面可用区域重新铺，跑出屏幕的宠物拉回来。
- **全屏时自动藏起来**：前台是别的程序的全屏窗口（视频、游戏）时，菌毯、菌斑、喷孢菌和宠物全部隐藏，退出全屏再出来，期间照样生长。
- **缩放**：菌毯每格 4px，在 125% / 150% / 175% / 200% 下正好是整数个物理像素，格子不会忽大忽小；110% 这类非常规缩放可能出现个别格子宽窄不一。
- **「只铺在桌面上」**模式在 Windows 按 Win+D（显示桌面）时会跟着被收起；默认的「铺在窗口上面」不受影响。
- 目前只铺主屏幕。

## 存档

`~/.local/share/fungi/save.json`，每次喂食、搬家、成长时立刻保存，另外每 30 秒自动保存。
存档损坏会自动备份成 `save.broken-<时间>.json` 并重新开始。同一个存档目录只能开一个程序。
